tl-db

Please be respectful of the server.

Download a replay: https://r2.tldb.haelp.dev/<id>

List replays for a user: https://tldb.haelp.dev/users/<id>. Returns a JSON array of replay data in the following format: 

[
  {
    "id": "<id>",
    "p1_uid": "<p1_uid>",
    "p2_uid": "<p2_uid>",
    "timestamp": <timestamp>
  }
]

List all replays: https://tldb.haelp.dev/replays. Returns a JSON array of replay data in the same format as above.

Get a decoded replay as JSON: https://tldb.haelp.dev/replay/<id>. Prefer decoding locally when downloading many replays.

Replay data format

Replays are stored in the compact TLR format (files start with the bytes TLR). Decode them with codec.ts (decodeReplay(bytes), runs on Bun or Node 22.15+), which needs the zstd dictionary at https://tldb.haelp.dev/codec/dict-v1.bin saved next to it as codec-dict-v1.bin. The format is described in FORMAT.md.

Older replays that have not been converted yet start with byte 0xd4 and are plain msgpackr data, which decodeReplay also handles. They were packed with: 

const packer = new Packr({
  bundleStrings: true,
  useRecords: true,
  structuredClone: true,
  useFloat32: 3,
  moreTypes: false,
});
