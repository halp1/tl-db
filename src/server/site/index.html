tl-db

Please be respectful of the server.

Download a replay: https://r2.tldb.haelp.dev/<id>

List replays for a user: https://tldb.haelp.dev/users/<id>. Returns a JSON array of replay data in the following format: 

[
  {
    "id": "<id>",
    "p1_uid": "<p1_uid>",
    "p2_uid": "<p2_uid>",
    "timestamp": <timestamp>
  }
]

List all replays: https://tldb.haelp.dev/replays. Returns a JSON array of replay data in the same format as above.

Get a decoded replay as JSON: https://tldb.haelp.dev/replay/<id>. Prefer decoding locally when downloading many replays.

Replay data format

Replays are stored in a custom TLR format. The decoder/encoder is available at codec.ts (function: decodeReplay(bytes)).

Note the zstd dictionary at https://tldb.haelp.dev/codec/dict-v1.bin must be saved next to it as codec-dict-v1.bin.
